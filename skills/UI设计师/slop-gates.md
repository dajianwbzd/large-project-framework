# 反 AI 默认风格门禁（slop-gates）

> **这份文件是规则的唯一来源。** `SKILL.md` 只写指针（§2「反 AI 默认风格门禁」），
> `scripts/slop_gate.py` **每次运行都现读本文件**取「规则集合 + Floor 标记」
> ——借 Hallmark 的做法（其 `gates.md` 与 `eval/score.mjs` 的分工，源码注释原话 `so the set never drifts`：
> 规则正文在 md 里，机器只从 md 里读"该查哪几条、哪几条不许破"，判据实现在代码里）。
>
> **改规则的唯一改法**：改下面这张表（加一行 / 改判据 / 挪 Floor），然后同步实现 `slop_gate.py` 里对应的
> `_check_<编号>` 函数。**不要在 SKILL.md 里重复列举规则，也不要把清单硬编码进脚本**——两处一抄就会漂移，
> 而漂移的门禁比没有门禁更糟（它让人以为查过了）。
>
> **漂移是可见的**：表里有规则而代码没实现 → 脚本以**退出码 2** 报「无法完整检查」，不是 0 不是 1。

## 怎么用

```bash
# 出稿前自查（方向稿 / 逐页稿 / 契约都行；给目录会递归扫 *.html / *.css / *.md）
python -X utf8 skills/UI设计师/scripts/slop_gate.py 契约/UI资源/directions

# 时间紧时只跑最小闸门（Floor 子集）
python -X utf8 skills/UI设计师/scripts/slop_gate.py 契约/UI资源/designs --floor-only

# 机器可读（进卡片的证据、给 lint 汇总用）
python -X utf8 skills/UI设计师/scripts/slop_gate.py 契约/DESIGN.md --json
```

退出码：**0** 无违例 ｜ **1** 有违例（可判档命中）｜ **2** 用法错 / 读不到本表 / 表与实现漂移
（**2 = 无法检查，不是"没问题"**——与 `solution_audit.py`、`recall.py` 的三态口径一致）。

## 三个档：脚本能不能自己下结论

| 档 | 含义 | 脚本行为 |
|---|---|---|
| `可判` | 判据确定，能从产物直接算出来 | 命中记 **violation**，影响退出码 |
| `半可判` | 需要人判，脚本只给线索 | 命中记 **advisory**，不影响退出码，但**必须进报告** |
| `人判` | 从产物判不了（要求人看、或要求知道意图） | 脚本只列「需人判」，**不表态** |

**不要给"半可判/人判"的规则标 Floor**——Floor 的意义是"机器一定拦得住的那几条"。

## Floor 子集（最小闸门）

Floor = **时间再紧也不许破**的几条（`--floor-only` 只跑这组）。入选标准三条：
**最可判**（判据无歧义）· **最常犯**（AI 默认审美的重灾区）· **一犯就露馅**（用户一眼看出是套路）。

当前 4 条：`SG-01`（紫/靛蓝渐变）· `SG-02`（一切圆角）· `SG-05`（重度阴影）· `SG-06`（占位文案）。
**Floor 规则不接受行内豁免**（见下）——它们就是不许破。

## 规则表

| 编号 | 规则 | 判据（脚本怎么查） | 档 | Floor |
|---|---|---|---|---|
| `SG-01` | 紫 / 靛蓝渐变成灾 | 扫 `linear/radial/conic-gradient(...)`；统计渐变里的色标，**色相 240–290° 且饱和度 ≥ 0.15** 记"紫蓝"，紫蓝色标占全部色标 > 50% 且渐变总数 ≥ 2 → 命中 | 可判 | ✅ |
| `SG-02` | 一切圆角 | 收集 `border-radius` 取值；**去重后 ≥ 3 档**、**最小档 ≥ 8px**、且**没有任何 ≤ 4px 的档** → 命中（= 所有容器都圆、且没有一档是"硬边"） | 可判 | ✅ |
| `SG-03` | 千篇一律 hero + 卡片网格 | `hero`（class/id/role 名含 hero）出现 + 同一 class 的重复容器 ≥ 6 个 → 命中线索（是否"千篇一律"要人看：重复容器是列表、表格也算合理） | 半可判 | — |
| `SG-04` | 超大内边距 / 留白 | 收集 `padding*` 的 px 值；声明 ≥ 4 处、且 **≥ 96px 的占 70% 以上** → 命中（内容被稀释成"高端大气"） | 可判 | — |
| `SG-05` | 重度阴影 | 收集 `box-shadow`；声明 ≥ 3 处、且**每一处的模糊半径都 ≥ 24px** → 命中（所有层级都靠大阴影，等于层级没设计） | 可判 | ✅ |
| `SG-06` | 占位文案 | 可见文本 / CSS 注释之外的文本命中：`lorem ipsum`、`示例文本`、`示例内容`、`待补充`、`待填写`、`TODO`、`你的标题`、`此处放图` | 可判 | ✅ |
| `SG-07` | 一切居中 | `text-align: center` 声明 ≥ 5 处且占全部 `text-align` 声明的 80% 以上 → 命中线索（对齐方式是否被思考过） | 半可判 | — |
| `SG-08` | emoji 当图标 | 可见文本里 emoji 字符出现 ≥ 3 个 → 命中线索（可能是卖萌，也可能是没做图标体系） | 半可判 | — |

**加新规则时**：① 先在表里加一行（编号顺延、写清可判据），② 再在 `slop_gate.py` 里实现同名 `_check_SG_nn`，
③ 跑 `python -X utf8 scripts/tests/test_slop_gate.py`（里面有"表里有规则没实现 → 退出码 2"的变异用例）。
**"可判"才配 Floor**；拿不准就标"半可判"，别把审美争议伪装成机器结论。

## 豁免（例外必须留痕）

```html
<!-- slop-gate: off -->           这一段整体关掉（含下面所有规则）
<!-- slop-gate: on  -->           恢复
<!-- slop-gate: off SG-02 -->     只关 SG-02
```

规矩三条：

1. **Floor 规则不接受豁免**（`--floor-only` 下更不接受）——紫渐变 / 全圆角 / 大阴影 / 占位文案没有"这次例外"。
2. 豁免必须**同时写一句理由**：方向稿写进「取舍说明」，逐页稿写进卡片的「进展记录」；`slop_gate.py`
   会把豁免单独列出来（**豁免 ≠ 没命中**，报告里要单列，不能靠关标记假装干净）。
3. 豁免是**给有意的破格**用的，不是给出稿偷懒用的：一个方向稿里超过 2 处豁免 = 这个方向大概没想清楚。

## 覆盖不到的地方（诚实边界）

- **拦不住"没想法"**：本表拦的是**默认审美惯性**（AI 一不追问就滑向的那一套），创意平庸、抄参考、信息层级烂，
  它一条都拦不住——那些归 §2 方向稿硬性要求、§3 用户选方向、两遍制走查 Pass 2 判断力。
- **拦不住配色好坏**：只拦"紫蓝渐变泛滥"这种模式化信号，配色和谐度、品牌契合度要人判。
- **文案腔**只粗筛了占位文案；"AI 腔"（三段式排比、"赋能/打造/一站式"）不在本表，属于下游「去 AI 味」工序。
- **CSS 只看文本**：`@media` / `:hover` 里的小写规则同样会被扫到（可能误报）；`var(--x)` 形式的取值脚本算不出来，
  会跳过并在输出里记 `unresolved`，**这类跳过不能算通过**。
- 判据阈值（0.5 / 8px / 96px / 24px / 70%）是**工程折中**，不是设计定律；项目里调阈值请改本表并在卡片记一句为什么。
