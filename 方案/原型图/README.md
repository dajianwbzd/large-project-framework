# 原型图（截图 / 页面图）

> 本目录只放**导出图**：低保真原型四档真图、高保真逐页图，给用户随时看"长什么样"。
> 真源：`project-state/契约/UI资源/prototypes/prototype.spec.json`（低保真唯一事实源）与 `project-state/契约/UI资源/designs/<页面>.html`（高保真正本）。图与真源冲突时**以真源为准，重新出图**。

## 出图口径（别手截）

- 四档真图一律 CDP：`node scripts/cdp_shots.mjs --routes flow,<屏…> --widths 375,1440` 这类命令产出的图才有效；
  `chrome --screenshot --window-size` 是**假档位**（布局视口会被钳），排除在验收链外。
- 文件名：`<页面或屏名>@<档位>.png`，例：`登录@375.png`、`登录@1440.png`。
- 每出一批图，登记 `清单.md` 一行（页面 / 档位 / 导出日期 / 源路径）；`solution_audit.py` 会核"图在但没登记"。

## 纪律

- 图不长期手改（PS/标注版请另存 `方案/原型图/标注版/`，并在 `清单.md` 备注写"标注版"）。
- 设计方向变更后**旧图不删**：挪到 `方案/原型图/历史/<日期>/`，在清单备注写"已被 <页面>@<档位> 取代"，避免用户看到两张都以为是最新。
