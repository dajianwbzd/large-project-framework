# 审核记录（追加式，每卡一条）

> **本文件是什么**：审计/验收类角色（安全审计 / 集成工程师 / 项目经理）对其他角色产出做**穿透审核**的结论汇总。
> **格式定义在 `契约/审核规范.md` §四**（`# 审核记录：<card-xxx>（<审核角色>）` → 结论 pass/存疑/fail → 被审核产出表 → 依据与复现命令）——**本文件只做追加容器，不复制模板，避免两处维护漂移**。
> **谁写**：安全审计 / 集成工程师 / 项目经理（他律角色）。测试工程师做黑盒功能验收，**不产审核记录**（见 `agent.md` 验收前置检查 4 与注意事项 17）。
> **为什么必须存在**：`agent.md` ⑥ 主控验收前置检查第 4 项要求「本文件存在且非空」——空则为配置性缺口，主控须先建骨架再收卡。
> **只追加不回改**：结论变更（如复验后 存疑 → pass）另起一条并列记录，标注复验依据，不覆盖历史条目（对齐「共享记忆区只追加不回改」纪律）。
