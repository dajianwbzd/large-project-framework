# API 使用文档（API Usage Guide）

> 版本：v1（随大型项目开发框架 **v4.0.0** 模板复制到项目）
> **L0 摘要**：面向**接入方/联调方**的人类可读 API 文档——把 `契约/api.yaml`（机器契约）翻译成"怎么接、怎么调、错了怎么办"。**唯一事实源仍是 `api.yaml`**，本文与之不一致时以 `api.yaml` 为准并立即修本文（不一致 = 契约漂移，按 `代码复查规则库.md` 域1 打回）。
> **维护人**：后端开发（交付前产出；`api.yaml` 每次变更同步本文）。**对外发布时导出/复制到 `交付/`** 并在 `交付/发出记录.md` 登记（对外件不落 `project-state/`）。
> **为什么有它**：`api.yaml` 是给工具看的契约，不是给人读的文档——v4.0.0 前"公共接口有文档记录"这条完成定义没有落点。
