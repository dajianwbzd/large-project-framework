## 一、布局（Layout）

> 用令牌名描述，不写裸值。栅格与间距全部来自 `DESIGN.md` 的 spacing 刻度。

```
┌─────────────────────────────────────┐
│ Header（bg-surface, padding: spacing.md）      │
├─────────────────────────────────────┤
│                                     │
│   Main（max-width 容器, gap: spacing.lg）      │
│   ├── 区块 A：<内容>                            │
│   └── 区块 B：<内容>                            │
│                                     │
├─────────────────────────────────────┤
│ Footer / 主操作区（sticky 与否）                 │
└─────────────────────────────────────┘
```

- 容器：`<max-width>`，居中/左对齐，页面内边距 `spacing.md`
- 区块间距：`spacing.lg`；区块内元素间距：`spacing.sm`
- 视觉层级：主操作用 `bg-brand`，次要动作降级为 `text` 变体（**一个区域最多一个 primary**）

| 断点 | 宽度 | 布局行为 | 组件降级 |

| mobile | 320 | 单列；主操作 sticky 底部 | Table → 卡片列表；隐藏次要列 <列名> |
| tablet | 768 | 两列 | 显示次要列 |
| desktop | 1024 | 左右分栏（侧栏 <宽度>） | 全量表格 |
| wide | 1440 | 内容居中，最大宽度 <值>，不横向拉伸 | — |
