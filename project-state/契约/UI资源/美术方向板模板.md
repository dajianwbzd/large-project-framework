# 美术方向板：<项目/模块名>

> UI设计师产出。复制本模板到 `project-state/契约/UI资源/美术方向板.md`。
> **仅 `game` 域需要**（v3.22.0）。这是游戏美术的"方向轴"，与 `DESIGN.md` 的关系是：**方向板讲"为什么这样"（人读），`DESIGN.md` 的 Art Tokens 与 `art-spec.json` 讲"具体是什么"（机器读）**。
> **为什么必须先有方向板**：没有风格支柱与色彩脚本，贴图尺寸、调色板区间、材质预算全无据可依，产出的资产必然各自为政。方向板六项是资产规格的前提，不是事后文档。
> **L0 摘要**：<项目>的美术风格支柱、参考来源、色彩与光照语言、剪影规则与预算上限。

> ⚠️ **诚实边界（调研实测）**：开源生态**没有** Art Bible 的权威模板，也**没有**剪影测试的成品工具。本模板是**清单 + 人判断**，不是"跑个工具就行"——**不要向下游假装它可自动**。唯一可直接抄结构的开源实例是 `0 A.D. Art Design Document`。

## 一、风格支柱（Style Pillars，3–5 条，必须互相制衡）

> 一句话一条，**能用来裁决争议**。写不出"互相制衡"就是没写——全是同方向的口号等于没有支柱。
> 检验法：拿两条支柱去套同一个取舍，应该能吵起来（那才说明它们真的在约束设计）。

| # | 支柱 | 它裁决什么 | 被它牺牲什么 |
|---|---|---|---|
| 1 | 例：**剪影先于细节** | 单位在远处/小尺寸先保轮廓辨识度 | 放弃近距离的高频细节纹理 |
| 2 | 例：**玩法优先于写实** | 交互物件的颜色饱和度可破环境色 | 放弃"真实世界里不会这么亮"的合理性 |
| 3 | <…> | | |

## 四、材质与光照语言（Material & Lighting Language）

> **同一项目内明暗方向必须统一**（0 A.D. 的做法：地形阴影统一画在特征左侧，匹配默认太阳角度）。方向不统一，资产拼在一起就会"各打各的光"，这是风格漂移最常见的成因。

| 项 | 约定 | 为什么 |
|---|---|---|
| 主光方向 | 例：左上 45°（全项目统一） | 资产拼在一起光源一致 |
| 色温策略 | 例：暖主光 + 冷补光 | |
| 金属度 / 粗糙度语义 | 例：粗糙度 ≤0.3 表示"可拾取"，>0.7 表示"背景" | 用材质传递玩法信息 |
| 对比策略 | 例：交互物件对比度高于环境一档 | 可读性 |
| 禁止项 | 例：不用纯黑 #000、不用纯白 #fff | 便于后续着色/滤镜不溢出 |

## 五、剪影规则（Silhouette Rules）

> **无成品开源工具**——这是清单 + 人判断。自检方式：把资产渲染成**纯黑剪影**（或纯 alpha 蒙版）后逐条看。

- [ ] 每个单位/角色在**纯黑剪影**下仍能辨别是什么（不看颜色）
- [ ] 同类资产（如同一职业的敌人）轮廓**不得互相混淆**——剪影差异点写下来：<如"高瘦 vs 矮胖 vs 带翼">
- [ ] 玩家角色与敌人剪影风格可区分（不靠颜色）
- [ ] 剪影在**目标最小显示尺寸**下仍可辨（小尺寸是剪影的真正考验）
- [ ] 交互物件（拾取/机关）在剪影或轮廓上有独有特征

## 六、尺寸与预算表（Budget）

> 预算的意义是**让美术与程序有共同上限**，避免"做到一半发现显存/帧率兜不住"。数值按目标性能档定，不是抄来的。

| 项 | 上限 | 说明 |
|---|---|---|
| texel density | <px/m> | 同一场景内资产密度需一致，否则贴图精度肉眼可辨地不齐 |
| 单张贴图尺寸 | ≤ <2048> | 2 的幂；写进 `art-spec.json` 的 `textures.max_resolution` |
| 单文件体积 | ≤ <5> MB | 写进 `textures.max_file_size_mb` |
| 每物体 UV 通道数 | 1 | 0 A.D. 的硬规则，简化管线与合批 |
| 每物体 Material 数 | 1 | 同上 |
| 图集 padding | ≥ 4 px | 防采样渗边 |
| UI 图集 | 必须关 Allow Rotation | 否则 UI 元素被旋转 |
| 像素画 | Point filter + 关 Mipmap + Lossless | 否则出现模糊/伪影 |
| poly 预算 | <角色 / 场景 / 道具 分别给> | |
| LOD 级数 | <n> 级 | |
| 调色板色数 | ≤ <n> 色 | 像素画尤其重要，写进 `art-spec.json` 的 `palette` 校验 |
