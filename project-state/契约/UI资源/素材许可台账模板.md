# 素材许可台账：<项目名>

> UI设计师维护。复制本模板到 `project-state/契约/UI资源/素材许可台账.md`。
> **仅 `game` 域需要**（v3.22.0），但**任何档位都不豁免**——素材许可是法务风险，与快速模式/A 档无关。
> **为什么必须记"许可快照"**：站点许可**会变**。调研实测案例——`Quaternius` 过去宣传 CC0，现已改为自定义 Quaternius Asset License (QAL)，禁止转售/再分发素材本身；`Freesound` 上大量素材是 `CC-BY-NC`（**不可商用**），极易被误用进商业游戏。**记"抓取当时"的许可文本摘要，才能事后自证。**

**字段口径**：
- **许可（SPDX）**：能填 SPDX 标识符就填（`CC0-1.0` / `CC-BY-4.0` / `CC-BY-NC-4.0` / `OFL-1.1` / `MIT`）。自定义许可填 `<自定义>：<名称+vN>`。
- **许可快照**：抓取当时页面上许可声明的原文摘要（一段话），**不是**"我记得是 CC0"。这是争议时唯一的自证材料。
- **可再分发**：能否把素材文件本身再分发（影响能否入库到项目仓库）。

## 二、红线（逐条核，命中即阻断）

- [ ] **无 `CC-BY-NC` 及任何 NC（非商用）许可**用于商业项目
- [ ] 全部 `CC-BY` / `CC-BY-SA` 素材已安排**署名位置**（游戏内致谢页 / 关于页 / 文档）
- [ ] **CC-BY-SA 的传染性**已评估（再分发可能要求同许可——多数商业游戏不适用）
- [ ] **字体**：默认只用 **OFL** 白名单；非 OFL 字体（含"免费商用"的自定义许可字体，如阿里巴巴普惠体/MiSans/HarmonyOS Sans/站酷系列）**逐份保存 EULA 快照**并人工确认
- [ ] **商业字库**（方正/汉仪/文鼎等）**一律不用**，除非有明确书面授权（字形比对维权成熟，高风险）
- [ ] **AI 生成素材**：记录了模型 + 版本 + 许可（Stability / Hunyuan 等自定义许可能限制商用收入门槛/地域）；已按平台要求**披露 AI 生成内容**（如 Steam）
- [ ] **素材入库**：`可再分发=否` 的素材**不入项目仓库**，只记获取方式与存放位置
- [ ] **无来源不明素材**：任何一行缺"来源 URL"即视为不合格

## 三、署名文案（可直接用）

> 放到游戏内致谢页 / 关于页。按许可要求生成，**逐条对应登记表的"需署名=是"行**。

```
本作品使用了以下第三方素材：
- <资产名> by <作者> (<来源 URL>)，许可：<许可名>
- <字体名>，许可：SIL Open Font License 1.1
```

> **OFL 字体署名要求**：保留版权声明与许可文本；**不能单独出售字体本身**；若修改字体，须改名（Reserved Font Name）。

## 四、变更与复核

- 素材**替换/下架**时：不删行，追加"状态"列标注（`在用` / `已替换（→#n）` / `已下架`）——保留历史以便追溯
- **每轮验收**由 UI设计师复核：登记表行数 vs 仓库内实际外部素材数量，**数量对不上即为 fail**
- 上游站点许可**复查**：项目重要节点（封版前）抽查一次来源页，若许可已变（如 Quaternius 式漂移）→ 更新快照并评估影响，记 `记忆/变更日志.md`（c-xxx）
