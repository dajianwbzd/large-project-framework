# 探索域（探索模式要探什么，v5.26.0）

> **这份文件回答一个问题：探索模式到底探哪些东西。** 没有它，`探索backlog.md` 就退化成"项目经理拍脑袋列活"。
> 四条关系：**探索域（地图）→ backlog（先探哪个）→ 夜班台账（探了多少）→ 三闸（什么时候停）**。
> 机检：`python -X utf8 scripts/scope_audit.py <项目根>`（**0 干净 / 1 有 ERROR / 2 无法检查**；空表 = 2，模板态如此）。

## 1. 三族：探索域的三个来源（问的三个不同问题）

| 族 | 问的问题 | 判据来源 | 取证方式 | 成本档 |
|---|---|---|---|---|
| **负面案例族**（`负面`） | **该拦的拦住了吗** | PRD 校验/权限条款、`api.yaml` | DOM + 接口 + 截图 | 便宜（档 B） |
| **真实数据族**（`数据`） | 拦不拦都不该，但**结果对吗** | PRD 数据语义、展示面条款 | 双通道对照（界面 ↔ 库/接口） | 中 |
| **体验负面族**（`体验`） | **操作过程里有没有让人怀疑系统的瞬间** | **`契约/EXPERIENCE.md` + 设计令牌** | **截图 / CLS / 录屏（视觉证据，必须有）** | 贵（档 A） |

**三族判据来源不同，这是设计上的关键**：指不到就是**规格空洞**（`status=空洞` → 生成 `补齐` 类 WU），**不许自己编期望值**（v5.24.0 铁律）。

## 2. 类型学（有界化的关键：值无穷、类型有界）

### 2.1 负面案例族（F1~F11）

| 编号 | 类 | 典型探针 |
|---|---|---|
| F1 | 格式错 | 手机号 12 位、日期 2026-13-45、金额三位小数 |
| F2 | 类型/空值 | 必填留空、填空格、粘超长、缺字段直接提交 |
| F3 | 边界 | 0、负数、阈值 ±1、单字段 1 万字符、极大金额 |
| F4 | 越权 | 改 id 看他人的单、降权后重放旧链接、遍历 id |
| F5 | 状态/时序 | 乱序操作、重复提交、双标签并发、撤回后再操作、跳步 |
| F6 | 依赖缺失 | 引用已删除对象、未选必填前置、外部资源不可用 |
| F7 | 注入与特殊字符 | SQL/HTML/脚本片段、emoji、零宽字符、超长中文、文件名特殊字符 |
| F8 | 数据量 | 一次导入 1 万行、列表 0 条 / 1 万条、超大附件 |
| F9 | 网络/会话 | 断网重连、会话过期、双击、返回后再提交 |
| F10 | 业务规则违反 | 自己审批自己、跳过审批链、额度不足、跨期操作、重复领取 |
| F11 | 文件/资源 | 上传错类型、0 字节、超大文件、文件名含 `../` |

### 2.2 真实数据族（D1~D6）

| 编号 | 类 | 典型探针 |
|---|---|---|
| D1 | 导出/下载内容 | 导出的是真 Word 还是 md 拼接、表格是否错位、文件名是否可打开 |
| D2 | 统计/汇总口径 | 同一指标在列表/详情/报表是否一致；合计对不上明细 |
| D3 | 列表↔详情一致性 | 列表显示 A、点进去是 B；分页后顺序漂移 |
| D4 | 跨端/跨视图一致 | 同一数据在手机端/桌面端、不同视图显示不一致 |
| D5 | 中文与特殊字符数据 | 真实中文文件名、超长中文、emoji、繁体、全角半角混排 |
| D6 | 空态/极值数据 | 0 条、只有 1 条、1 万条、全空字段、全是同一值 |

### 2.3 体验负面族（E1~E8）

| 编号 | 类 | 典型症候 | 可机测 |
|---|---|---|---|
| E1 | 布局稳定性 | **屏幕上下抖动**、内容跳位、滚动位置丢失 | ✅ `LayoutShift`（CLS）超阈值即命中 |
| E2 | 反馈缺失 | **无进度条**、点了没反应、无成功/失败提示 | ⚠️ 部分（DOM 里有没有 loading/progress 元素） |
| E3 | 状态与禁用 | 重复点击、双击重复提交、按钮不禁用、表单填一半丢了 | ✅ 点击后按钮是否 `disabled` |
| E4 | 长任务感知 | 长任务无排队提示、无骨架屏、无预计时间 | ⚠️ 部分（骨架屏元素 + 首字时间） |
| E5 | 失败可恢复 | 失败后无法重试、返回丢数据、只能刷新重来 | ⚠️ 需人眼/流程走 |
| E6 | 可见性与溢出 | 内容被截断、被浮层挡住、窄屏横向溢出 | ✅ 滚动宽 > 视口宽 = 溢出 |
| E7 | 一致性 | 同类操作不同反馈、文案前后矛盾 | ⚠️ 需成对对照 |
| E8 | 可访问性底线 | 对比度不足、键盘不可达、无 aria | ✅ 部分 |

> **E1 是这套设计里最值得强调的一条**：抖动**不用靠肉眼判**——`PerformanceObserver` 取 `layout-shift`，给个阈值（建议 CLS > 0.1）就是机器判据。**体验族里"可机测症候"与"需人眼症候"要分开**，否则整族都会变成"凭感觉"，WU 又会灌水。

## 3. 负向边界（不划这条线，"什么都能算"）

| 不算探索域 | 归谁 |
|---|---|
| 纯视觉审美（"圆角不好看"） | 无契约判据 → 只记建议，不算发现、不计 WU |
| 性能/容量（p95、首包体积） | 测试维度 ⑨（有专门环节与预算） |
| 安全渗透（注入打穿、提权链） | 安全审计（本域只覆盖"该拦没拦"的行为面） |
| 基础设施/环境（部署、证书、磁盘） | 运维 |
| CUA 执行器本身（"怎么点"） | 执行层，不在本域 |

## 5. 探索域本体（机读块；一行一条探针）

| 列 | 含义 | 判据 |
|---|---|---|
| `id` | 探针号 `S-NNN` | 唯一、升序；重号乱序 = ERROR |
| `family` | 族 | `负面` / `数据` / `体验` 三选一 |
| `kind` | 类型编号 | 负面 `F1~F11` / 数据 `D1~D6` / 体验 `E1~E8`；**前缀必须与族匹配**（串族 = ERROR） |
| `target` | 目标面（旅程/页面/接口） | 非空（空 = 这条探针没有对象） |
| `identity` | 以谁的身份打 | 非空（未登录/普通用户/管理员/刚被降权/他人数据持有者/自动化调用方…） |
| `channel` | 从哪打 | `界面` / `接口` / `文件` / `消息` / `定时` |
| `face` | 看哪个可见面 | 列表/详情/直达链接/导出/搜索/通知/统计/无 |
| `criterion` | **判据来源** | 指向契约（形如 `契约/EXPERIENCE.md#UX-INS-03`）；路径部分必须存在；空 ⇒ `status=空洞` |
| `risk` | 优先级 | `P0` / `P1` / `P2` |
| `evidence` | 必须留下的证据 | 截图/DOM/接口/库/CLS/录屏；**体验族必须含 截图·CLS·录屏 之一** |
| `status` | 状态 | `待探` / `已探` / `空洞`（空洞 = 等 CR 补契约） |

## 6. 怎么用（和 backlog / 台账的接口）

1. **backlog 的每条 WU 必须指到某一格**（判据指针写 `契约/探索域.md#S-NNN`）或直接指到契约条款；**指不到 = 凭空派活**，`scope_audit.py` 报 ERROR。
2. **`status=空洞` 的格不进 backlog 的 `发现`**——它生成 `补齐` 类 WU（提 CR 补契约），补完再改成 `待探`。
3. **探完改 `已探`**，并在夜班台账记一行（`发现` 或 `修复`；体验轻微是否单列 WU 由 PM 定，见注意事项）。
4. **一条发现 → 同类推广**：把「同类风险面还有哪里」写成新的 `S-NNN` 追加进本表（只增不改），这正是"活的自增殖"。

## 7. 首测怎么做（真实项目第一夜，建议 2 小时）

```bash
# 1) 先看门禁现状（没填域表时会返回 2，属正常）
python -X utf8 scripts/scope_audit.py <项目根>

# 2) 从项目文件里挑 5~8 条旅程，填第 5 节的机读块（先填 P0/P1 各几条即可，别求全）

# 3) 再跑一次：0 才算域表可用
python -X utf8 scripts/scope_audit.py <项目根>

# 4) 按域表派活 → 每轮记 问题/夜班台账.md → 每 3 轮判闸
python -X utf8 wu_ledger.py（v5.27.0 已随夜班机制删除） <项目根> --gate
```

**首测只验三件事**（不追覆盖率）：① 域表能不能指向真实契约条款；② 体验族的视觉证据能不能留下来；③ `--gate` 会不会在没达标时真的拦住你。
