# 变更日志

> 契约/代码变更后强制记录，确保所有角色感知最新状态。
> 编号规则：`c-xxx` 递增；需求卡「相关记忆」区引用变更条目，避免基于过期契约开发。
> 分组规则（借鉴 git-workflow-and-versioning）：按影响类型归组，随变更同步书写，**同一时间只描述当前状态**（不写变更历史流水账）。
