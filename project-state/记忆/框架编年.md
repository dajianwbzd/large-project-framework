# 框架编年（版本历史与机制来历）

> **本开源仓库不收录实战编年。**
>
> 本仓库发布的是框架的**方法与脚本**。框架在真实项目上迭代时留下的逐版实战记录（客户、项目细节、真实数据、内部决策过程）属于内部资产，不随开源仓发布。
>
> **版本口径**：当前版本只以 `agent.md` frontmatter 的 `version` 字段为准（本仓当前 v5.28.0）。
>
> **查「某机制自哪版起、为什么」**：`agent.md`、`project-state/注意事项.md`、`project-state/验收标准.md`、`project-state/完成定义.md` 各条款里的 `（vX.Y.0…）` 都是**历史归属标注**，全仓保留、不随本文件缺失而消失；按机制名在那三份契约件里检索即可定位。
>
> **项目侧仍然照常工作**：旧项目迁移与漂移比对走 `scripts/migrate.py` 与 `scripts/framework_lint.py` 的既有机制，不依赖本文件内容；`migrate.py` 在需要时会自行生成完整的编年底稿。
